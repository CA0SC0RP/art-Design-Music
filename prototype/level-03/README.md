# Nivel 03 — escena viva avanzada

## Objetivo
Probar una escena compuesta donde convivan sistemas de movimiento distintos y ciclos independientes, con control global de pausa y velocidad.

## Sistemas incluidos
- 12 estrellas con parpadeos escalonados y periodos diferentes.
- Luna con variación de resplandor.
- 2 grupos de nubes con velocidades distintas.
- 3 aves con trayectorias y aleteo.
- 5 luciérnagas con desplazamiento y pulsación luminosa.
- 2 mariposas con trayectoria flotante y batido de alas.
- 3 hojas con caída y rotación.
- 2 grupos de árboles con balanceo sutil.
- Cascada con textura de flujo animada.
- 2 trazos de corriente del río y 3 ondas expansivas.
- 2 peces con nado y cambio de dirección.
- Control de pausa/reanudación y control de velocidad global.
- Respeto por la preferencia del sistema de movimiento reducido.

## Implementación
SVG vectorial, animaciones CSS con duraciones y desfases independientes, variables CSS para modular la velocidad, y JavaScript únicamente para los controles de escena. Es una prueba de técnica y carga, no una composición artística final.

## Validación pendiente
Abrir en Firefox, comprobar cada familia de movimiento, pausar/reanudar, recorrer el control de velocidad y observar fluidez. Después validar Safari en iPad. Chrome sigue pendiente de diagnóstico separado.
