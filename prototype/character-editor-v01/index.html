Biblioteca de poses
Una pose guarda la posición, rotación y escala de todas las piezas. Se incluye en el proyecto y en el JSON exportado.
Expresiones faciales
Las expresiones modifican cejas, ojos y boca. Puedes guardarlas como poses.
Malla editable y pesos
Selecciona una pieza y crea una malla. Después podrás mover sus vértices y asignar influencias de huesos.
Movimientos coordinados
Acciones de prueba que coordinan hombro, antebrazo, mano, muslos y piernas. Puedes guardar el resultado como una pose propia.
Control de cadena · IK 2D
Arrastra el marcador del lienzo para mover la mano o el pie. Fijar bloquea el marcador; liberar permite volver a moverlo.
